# daysoff

Vacation bridge calculator — find the optimal combination of PTO days to maximize consecutive time off by leveraging public holidays and weekends.

Static Astro site served by nginx. No backend, no database.

## Quick start

```bash
docker run -p 8080:8080 sisqueslabs/daysoff:latest
```

Then open http://localhost:8080.

## Ports

| Port | Purpose         |
| ---- | --------------- |
| 8080 | HTTP (static site) |
